Exercise: Scale Institutional Knowledge Using Copilot Spaces

## Chatbot Application

This repository contains a simple Python chatbot that can interact with users through a command-line interface.

### Features

- Interactive conversation using pattern matching
- Responds to greetings, questions about time, and general chat
- Simple and easy to use
- No external dependencies required

### Requirements

- Python 3.6 or higher

### Installation

1. Clone this repository
2. No additional dependencies needed - uses only Python standard library

### Usage

Run the chatbot by executing:

```bash
python chatbot.py
```

Or make it executable and run directly:

```bash
chmod +x chatbot.py
./chatbot.py
```

### How to Chat

Once started, the chatbot will greet you. You can:

- Say "hello" or "hi" to greet the bot
- Ask "what is your name?" to learn about the bot
- Ask "what time is it?" to get the current time
- Ask "how are you?" to see how the bot is doing
- Say "help" to learn what the bot can do
- Say "bye" or "goodbye" when you're done
- Type "quit" or "exit" to end the conversation

### Example Conversation

```
ChatBot: Hello! I'm ChatBot. Type 'quit' or 'exit' to end our conversation.

You: hello
ChatBot: Hi there! What's on your mind?

You: what is your name?
ChatBot: I'm ChatBot, your friendly chatbot!

You: what time is it?
ChatBot: The current time is 14:30:45

You: bye
ChatBot: Goodbye! Have a great day!
```
